# Kinetic Logic Labs — Homepage Directions

These are standalone, non-production concepts. They share the current site's rough content (engineering, CAD, Science Olympiad, and selected work) but intentionally use different composition, hierarchy, navigation, and media strategies.

| File | Direction | Core idea |
| --- | --- | --- |
| `01-field-notes.html` | Field notes | A quiet research journal with a single featured artifact. |
| `02-atelier.html` | Editorial atelier | A high-contrast magazine layout with a project-led entry point. |
| `03-systems-index.html` | Systems index | A structured engineering catalogue, led by evidence and metadata. |
| `04-kinetic-studio.html` | Kinetic studio | A bold split-screen portfolio with media as a primary navigation device. |
| `05-research-ledger.html` | Research ledger | A linear publication-style homepage that foregrounds methods and outcomes. |

Open any HTML file directly in a browser. All image paths point to existing assets in `src/`; none of these files are imported by the application.
